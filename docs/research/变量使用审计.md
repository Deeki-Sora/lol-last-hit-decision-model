# 补兵时机参数化决策模型：变量使用审计

结论：模型中的变量不是全部直接代入同一个最优动作公式，但核心变量均已进入策略演算的某一条路径。

## 直接参与动作演算

- (S,Omega,G,mathcal E)：状态、信念、攻击关系图和事件队列。
- (t_0,T_{end},\mathcal M^{task})：窗口、终止条件和任务兵集合。
- (K_i,\beta_c,\gamma_{minion\ attack})：单位数据、对兵伤害和版本机制。
- (\mathcal L,\mathcal C,\mathcal F_A)：可补命中、可执行出手和自由时间。
- (P(b\mid\Omega,a),J,Q_t,V_t)：敌方分支、收益、在线决策、有限搜索递推。
- (W)：金币、经验、状态成本和风险的权重。

## 作为搜索辅助量

- (\Phi_A)：行动压力，决定优先检查哪些目标。
- (M_{h,i})：英雄到目标的相位余量。
- (\Delta M_i)：动作对后续补刀余量的改变。
- (VOI)：等待或试探动作的信息价值。
- (I_{coupled})：判断动作是否进入补兵核心搜索。

这些变量不一定直接出现在最终 (Q_t) 公式里，但会改变候选集合、截止期、事件分支或动作排序，因此实际影响决策。

## 只用于事后核验

\(\ell_{behavior}\) 比较动作发生后的目标、类型、顺序、时间和等待。它需要未来实际动作作为标签，不能进入实时决策奖励，否则会产生未来信息泄漏。

因此，模型目前不存在“定义后完全闲置”的核心变量；但变量的作用层级不同，不能要求每个变量都直接出现在最终目标函数中。
