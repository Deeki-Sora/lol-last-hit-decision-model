# 录像中的像素距离记录

以首波小兵交汇处可持续辨认的地图纹理点为固定原点。每帧追踪该点在画面中的位置，用各单位血量条中心作为观测标记，沿画面右方为 x 正方向、下方为 y 正方向。

设单位血条中心为 \(b_i(t)\)，纹理原点在当帧的位置为 \(o(t)\)：

\[
p_i^{px}(t)=b_i(t)-o(t),\qquad
d_{ij}^{px}(t)=\|b_i(t)-b_j(t)\|_2.
\]

跨帧位移与时间间隔记录为：

\[
\Delta p_i^{px}=p_i^{px}(t_2)-p_i^{px}(t_1),\qquad
\Delta t=t_2-t_1.
\]

同帧相对距离可直接由两个中心计算，即使该帧原点被遮挡；跨帧移动需要可追踪的原点与一致的镜头尺度。平移补偿不等于缩放或透视补偿，镜头缩放后应使用不同的尺度标识，或在校准后再比较。

记录至少包括：原视频时间、持久单位编号、血条中心、当帧纹理原点、像素距离、动作阶段、观测或估计标记及不确定范围。中心无法确认时保留未知；相邻帧估计应单独记录取样范围，不当作当前帧直接观测。

血条中心距离是画面度量，不是地面碰撞边界。未建立尺度与偏移校准时，不把像素除以官方移速，也不直接与官方普攻或施法距离比较。可用它检查相对接近、后撤、攻击前后间距和动作间隔，可能的地面距离则另附区间及校准依据。
