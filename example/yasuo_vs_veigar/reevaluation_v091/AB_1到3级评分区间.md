# 四名玩家 1–3 级表现：评分区间

评分版本：**AB-L1-L3-interval-1.0**。

| 玩家 | 共同可评项目的评分区间 |
|---|---:|
| A 亚索 | **63–86** |
| A 维迦 | **47–75** |
| B 亚索 | **71–94** |
| B 维迦 | **56–85** |

只评价第一波交战至双方首次达到三级。A1/A2 合并；A 在约 2:06 的截止记录为 10/12 刀，维迦 518/860 生命；B 截止记录为 17/11 刀。三级后的交换与回城均不计入。

## 区间口径

采用相同的策略 65%、执行 35% 权重及四人共同可评项目。共同项目占原评分总权重的 63%；没有完整证据的冷却、符文、精确反事实损失等不填分，也不因缺失而扣分。

区间反映三个争议项目的判断敏感性：**窗口识别、成本转换、资源兑现**。对四人使用完全相同的规则，将每项原始等级分别上下放宽一档，即 0.25，限制在 [0,1]；其他编码保持固定。

设固定输入的分项等级为 \(q_{h,j}\)，则

\[
[l_{h,j},u_{h,j}]=
\begin{cases}
[\max(0,q_{h,j}-.25),\min(1,q_{h,j}+.25)],&j\in J,\\
[q_{h,j},q_{h,j}],&j\notin J,
\end{cases}
\]

其中 \(J\) 是上述三个争议项目。每一层只在共同可评项目内归一化，保持策略和执行的 65/35 比例。因权重均为正，分别代入全部下界和上界即可得到综合分下界和上界；展示时向外取整。

这是一项明确、统一的区间约定，不是由大样本估计的误差分布，也不是统计置信区间。它保留了人工编码的条件性，不能解释为完全客观的真实能力边界。未计入的 37% 权重及其他分项可能存在的判断误差，也不在这个区间内。

## 如何比较

- **A 亚索与 B 维迦：区间明显重叠，不确定谁更好。**
- 两名亚索的区间重叠，两名维迦的区间也重叠，均不能据此严格排序。
- B 亚索的可见主动窗口利用证据较强；A 维迦有局部位置与交易成本问题。这些证据支持评价方向，不足以把点数差当作稳定水平差。
- 区间不取中点替代单点排名，也不映射为段位或整场比赛水平。

## 固定与复算

本版本的输入、规则和结果分别保存于 [输入快照](interval_v1/inputs.json)、[区间规则](interval_v1/policy.json)、[结果](interval_v1/result.json)，并由 [SHA-256 清单](interval_v1/lock.json)核对。运行：

```powershell
python example/yasuo_vs_veigar/reevaluation_v091/score_intervals.py
```

[复算脚本](score_intervals.py)只读取固定快照，不重新人工打分，也不读取会继续变化的工作输入。输入、规则或脚本发生变化时会拒绝将其作为本版本复算；复算结果必须与保存结果一致。

无新证据或无明确规则版本变化时，继续引用本表。证据补全、截止点纠正或评分规则变化应使用独立版本，保留原版本结果，并明确变化依据。同一版本、同一输入得到同一区间；合理修正可以改变结果，但不能静默覆盖。
