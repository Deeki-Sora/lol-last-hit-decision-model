# 补刀站位原则：普通玩家交互版 v3

这个工具回答三个问题：现在站哪里能补刀？能否保留施法机会，具体消耗技能是否够得到对面？如果直接补不到，能否用技能或趁对面A兵后上前补一刀再撤？

## 怎么运行

需要 Python 3，无第三方依赖。在当前目录运行：

```powershell
python 补刀站位_交互输入版_v3.py
```

## 不清楚的参数怎么填

有默认值的输入可以直接回车。

| 参数 | 回车后的处理 |
|---|---|
| 英雄和小兵的体积半径（玩法半径） | 0，按点估计 |
| 技能范围半径、技能宽度 | 0，不额外扩大技能范围 |
| 普攻距离、技能距离、安全裕量 | 0，按输入值计算 |
| 我方最大施法范围 | 0，跳过保留施法范围的要求，仍可找普攻补刀位置 |
| 敌方最大施法范围、我方消耗技能距离 | 跳过，不据此判断敌方施法范围或己方消耗可达性 |
| 敌方技能类型 | 跳过，不判断具体技能命中 |
| 反应时间 | **0.28秒**，通用参考值 |
| 我方普攻前摇，且不知道攻速 | **0.30秒**，普通普攻样本平均的近似 |
| 敌方普攻前摇，且已输入攻速 | **20%÷攻速**，通用前摇比例近似 |
| 移速、对面下一次普攻所需时间、敌方攻速 | 可填0；必要时间信息不足时，不给出窗口成立结论 |

0只是简化估计，不表示游戏里的真实体积或范围为0。尤其是把敌方体积或技能范围忽略，会低估风险；有数据时再填真实值或合理估计即可。敌方移速为0时按不追击估算，会明确提示这一点。

三个坐标是必需信息：敌方英雄、敌方准备补刀的我方残血兵、我方准备补刀的敌方残血兵。原点是兵线交汇中心，x轴左下→右上，y轴左上→右下。输入如 `100 -100`，也支持逗号。

## 普攻距离和技能距离怎么选

先区分三项：

- **敌我最大施法范围**：各自当前所有可用技能中施法范围最大的那个，可以来自护盾、治疗等非伤害技能。它只用于距离参考，不能据此判断能否消耗或造成伤害。
- **你的消耗技能距离**：填写该技能能打到的有效距离，已估入作用范围；不再由程序额外扩大。例如圆心距离1100、作用半径310、目标半径0时，可以估计为1410。
- **技能补刀距离**：普攻补不到时，交互程序自动沿用消耗技能距离计算候选区间，不再询问一套补刀技能参数。最大施法范围仍单独计算。

交互中默认用同一距离估算消耗与技能补刀，不重复加目标体积或技能作用半径；不同目标大小造成的实际命中距离差异需要自行估计。该技能是否能伤害小兵、能否收掉残血，仍需看技能效果与伤害。程序核心保留单独指定补刀技能形状与尺寸的能力，供独立计算使用。

最大施法范围统一到中心参考口径；圆形技能填圆心最远施法距离，不把爆炸半径加进去。全图技能不能用有限距离表达时，目前可跳过最大范围输入；这不等于它在游戏中没有施法范围。

普通普攻一般按双方玩法圆的**边缘到边缘**判定，不能把资料里的普攻射程直接当作两单位中心之间的距离。脚本提供两种方式：

1. **自己估计／已经计入体积**：输入两单位中心之间能A到的距离，程序不再加体积。
2. **游戏或资料中的射程**：输入普攻距离和双方体积，后台加上攻击者与目标的玩法半径。不知道体积可以回车取0，按点近似。

多数指向性技能按**中心到中心**判定，但存在例外；非指向技能还要看飞行距离、宽度或爆炸范围。技能不能一律套用普攻的体积修正。

- 指向性／已经估计好的技能距离：输入两单位中心之间能打到的距离，不再加半径。
- 需要防范的圆形敌方技能：距离从**敌方英雄中心**量到**技能圆心**，不从英雄边缘量起；圆形范围的半径另填。
- 直线非指向技能：输入纵向距离和全宽。查到的是半宽时，乘2再填。

查证参考：[LoL Wiki距离说明](https://leagueoflegends.fandom.com/wiki/Range?page=3)、[Riot官方14.9半径说明](https://www.leagueoflegends.com/en-gb/news/game-updates/patch-14-9-notes/)、[Riot官方12.2技能距离改动](https://www.leagueoflegends.com/en-gb/news/game-updates/patch-12-2-notes/)。后两项分别说明体积会影响普攻判定，以及技能确实存在边缘与中心两种口径；具体英雄以对应版本的技能说明为准。

## 找不到理想位置时会怎么处理

按以下顺序给出结果：

1. 找能普攻补刀、又处于己方最大施法范围内的位置，保留施法机会。是否能消耗，按另填的具体消耗技能距离逐点提示。
2. 找不到时，**先找能普攻补刀的位置，不再强求处于最大施法范围内**；具体消耗技能仍单独判断。
3. 普攻仍够不到时，自动按已填写的消耗技能距离检查技能补刀位置；未填写则不判断这一项。
4. 只要不能直接普攻补刀，就保留“对面A完兵后，上前补一刀再退回来”的计算入口。即使有技能补刀方案，也能继续比较。
5. 都不合适时，考虑等对面后撤、换方向，或放弃这一刀。

程序默认只显示结论、可站范围的二维坐标和激进／平衡／保守三个参考点，不显示切点Q、切线参数s等计算术语。后台仍保留完整公式；开发者可用 `print_all(g, details=True)` 查看区间与约束。

每个推荐点及等待点都会说明“敌方是否在己方最大施法范围内”，即使已回退为只补刀或技能补刀也会显示。这个距离参考仍与具体消耗技能的可达性分开判断。

敌方非指向技能的提示只检查对面朝兵线方向释放时的静态范围是否覆盖该点。范围未覆盖不代表已经躲开；对方改变方向或落点仍可能命中。目前没有模拟技能弹速、施法延迟和飞行期间的躲避动作，因此不默认保证玩家能在技能到达前移动出去。

推荐位置沿当前兵线方向构造，不代表整个地图上的全部可行位置。裕量为0时，推荐范围可能包含普攻边界点，贴边仍可能被A到。

## 对面A完兵后的短时窗口

我方执行：反应→上前→普攻出手→回到等待位置→继续后撤。对面A兵出手后立刻追击。

输入移速和时间后，程序检查：对面下一次普攻转好时，我方是否已经A出这一刀、退回等待位置，并且有足够距离余量。任何一项没做到，都不报告这条补刀路线可行。

不清楚反应时间或前摇，可以用默认值；知道自己或英雄的数据时可覆盖。默认值的来源与限制：

- 反应0.28秒：参考[Human Benchmark点击反应统计](https://humanbenchmark.com/tests/reactiontime/statistics)的平均284毫秒，取两位小数。它是简单视觉点击任务的参考，**不是实战补刀决策的实测平均**。
- 前摇0.30秒：按[Riot官方13.22更新](https://www.leagueoflegends.com/en-us/news/game-updates/patch-13-22-notes/)中Ahri、Heimerdinger、Xerath的历史基础攻速0.668、0.658、0.658及20%前摇比例，推算秒数后取平均约0.302秒，再取两位小数。它是历史三个普通普攻样本的参考，**不是全英雄、所有攻速状态的平均**。
- 已知攻速时，可以按20%前摇比例换算，或直接填对应英雄的真实秒数。特殊前摇、强化普攻和攻击重置请采用真实数据。

窗口从敌方**攻击出手**开始，所以后台使用剩余时间 `1/敌方攻速 - 敌方前摇`，而非整个攻击周期。也可直接估计下一次普攻转好还需几秒。

A出这一刀不代表兵已死亡，还要看伤害和弹道。默认值、零体积或零技能范围都会降低估算精度；技能、地形、阻挡和普攻重置不由这个距离模型保证。

## 可以统一缩放吗

可以。所有坐标、普攻距离、技能距离、体积、技能尺寸、安全裕量和移速都同比缩放；秒数、前摇比例、攻速不缩放。

例如长度缩小100倍：600→6，65→0.65，移速325→3.25；反应0.28秒仍填0.28，攻速0.658仍填0.658。不会因为输入5不符合官方数值范围而拒绝计算。
