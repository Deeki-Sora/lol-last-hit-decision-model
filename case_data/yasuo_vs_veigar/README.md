# 亚索 vs 维迦案例档案

## 视频与时间映射

- **A**：[A1/A2 合并观看版](media/A_merged.mp4)。保留 A1 原视频的 `[0,44.8)` 秒，随后接入 A2 原视频全部内容，去掉 A1 尾部与 A2 开头重叠的约两秒。
- **B**：[原视频](media/originals/B.mp4)。
- 原片：[A1](media/originals/A1.webm)、[A2](media/originals/A2.webm)。
- [来源文件名、SHA-256 与合并参数](media/source_manifest.json)。

合并视频中的 A2 时间为 `44.8 + A2 原视频秒数`。接缝依据 HUD 与共同事件对齐，约有一秒时间不确定性，且存在观战选择目标和镜头位置切换；不声称逐帧无缝。原视频完整保留，证据核验仍优先使用原片时间。

[A 合并动作索引](A_combined_action_index.csv)记录原片、原表行号、原视频时间和合并视频时间。原表中的游戏时钟标签保留为历史待核验字段；合并不等于重新确认每行动作。
